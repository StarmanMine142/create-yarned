# Create: Yarned
Fun port of Create mod to 1.21.1 fabric

Named after Yarn mappings by FabricMC. Rest in Peace Yarn 2016-2025.<br>
(Although Yarn mappings will not be used here).

Since this is a fun port, I can't promise future support for it, or that the port will be completed (especially considering that I hardly know how to write code).

Not affiliated with [Creators of Create](https://github.com/Creators-of-Create) or [Fabricators-of-Create](https://github.com/Fabricators-of-Create), the project was created on pure enthusiasm.

Currently only the build scripts are ported
